# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue or discussion:

- through GitHub: [report a vulnerability](https://github.com/krantro2938/coffer/security/advisories/new), or
- by email to coffer-support@aansl.com.

Say what you found and how to reproduce it. You will get a reply within a few days. Please give us a reasonable
chance to fix the problem before you publish it; we will credit you in the fix unless you would rather not be named.

## What is in scope

The code in this repository, and the service run from it. Especially welcome: anything that lets the server or a
third party read file contents, names or keys; anything that lets one account reach another's data; anything that
lets a link do more than it was made to do.

## What to know first

[docs/security.md](docs/security.md) describes what Coffer protects, how, and where the protection stops. The
limits listed there are known. Coffer has not yet had an independent security review.
